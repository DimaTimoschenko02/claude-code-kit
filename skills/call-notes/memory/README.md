# Память разбора звонков

Claude читает эту папку перед каждым разбором и сам дописывает сюда то, что узнал. Править руками тоже можно.

Стартовый набор — не жёсткий список:

| Файл | Что в нём |
|---|---|
| `me.md` | Кто владелец, куда сохранять разборы, на каком языке |
| `people.md` | Люди: кто это, как расшифровка пишет имя |
| `words.md` | Слова и названия, которые расшифровка коверкает |
| `calls.md` | Журнал разборов: какой звонок, где файл, что осталось открытым |
| `corrections.md` | Поправки к разборам: что было не так и как делать теперь |

Память растёт сама. Файл разросся — его можно разбить, например на `people/<имя>.md`. Появилась тема, которой
нигде нет, — например поставщики или проекты, — для неё заводится новый файл. Каждый новый файл получает
строку в этой таблице, иначе его не найдут.
